AI Impact on Jobs 2030

An exploratory data analytics project examining how artificial intelligence may affect jobs and workforce trends through 2030.
The project uses SQL for data exploration and Power BI to present indicators such as AI replacement risk, future demand, job growth, hiring trends, 
automation levels, and workforce characteristics.

>> Project Overview

The purpose of this project is to help readers explore the potential relationship between AI adoption and the future of work. 
The Power BI report provides an interactive view of the available data, with comparisons across job sectors and filters for factors such as country 
and company size.

The project is intended for learning and exploratory analysis. Its indicators should be interpreted in the context of the dataset.

>> Questions Explored

- How do AI replacement risk and future demand vary across job sectors?
- What job-growth and hiring-trend indicators are represented in the data?
- How do automation and upskilling needs differ by sector?
- What workforce characteristics—such as education level and remote-work possibility—are included in the analysis?
- How can these indicators support workforce-planning discussions?

>> Tools

- **Power BI** — Data modeling, measures, visualizations, and interactive report.
- **SQL** — Data exploration and aggregation.

>> How to Use

1. Download or clone this repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Use the report filters to explore available countries, company sizes, and job-sector comparisons.
4. Review the SQL script to see the queries used for data exploration.

>> Notes and Limitations

The report presents indicators from the included dataset; it does not establish that AI alone causes observed job-market patterns.
Results depend on the dataset, its definitions, and how measures are calculated. Confirm the source, scope, and units of each field before 
using the analysis for business or policy decisions.
